# 模型供应商

[English](model-providers.md) | 中文

Autoloom 不包含模型用量。模型访问、计费、限流、数据处理和可用性由你选择的供应商决定。

## 添加供应商

打开**设置 → 模型**。

- 如果列表中已有对应供应商，使用内置目录项，填写该供应商要求的凭据并保存。
- 对于提供受支持登录或订阅流程的供应商，在**账户**中完成授权；不透明授权记录会保存在 Windows 凭据管理器中。
- 公司网关、自托管服务或未列出的 OpenAI 兼容接口可使用**添加自定义供应商**，填写固定的小写供应商 ID、基础地址、协议、凭据和至少一个模型。

自定义供应商 ID 会进入已保存的模型选择与凭据引用。需要更换 ID 时，请新增供应商，不要直接改名。

在模型页面保存的 API Key 对界面只写不可读：Renderer 只能得到已遮盖的描述，不会收到原始值。密钥保存在 Autoloom 数据目录下受管理的凭据文件中。详见[数据与隐私](../DATA_AND_PRIVACY.zh-CN.md)。

## 选择模型

保存供应商后请选择默认模型。Session 可以单独指定另一个模型；选择**跟随全局**后，会重新使用当前全局默认值。全局默认值的变更会在跟随它的 Session 下一次请求时生效，不会改变已经发出的请求。

如果已保存的 Session 指向后来被删除的供应商，发送新消息前需要重新选择模型。

## 自定义接口与图片

接口即使接受密钥，也可能因为 API 与所选协议不一致而拒绝请求。请核对供应商文档中的基础地址和协议。部分实现 OpenAI 兼容 API 的网关，可能需要调整请求角色、token 上限或推理字段；当前表单并不提供所有兼容性开关。

手动填写的模型默认按纯文本模型处理，只有配置明确声明图片输入时才会发送图片。所选模型未声明图片能力时，Autoloom 会在发送前拒绝附件。声明能力只表示允许发送，并不能证明接口实际支持图片。

## 会发送什么

每一轮任务都会把组装后的请求发往所选接口，其中可能包含系统指令、对话历史、工具定义与结果、选中的文件内容和附件。凭据用于授权请求，不会写入对话内容。处理敏感项目之前，请先阅读供应商自己的隐私与留存政策。

## 网页搜索与指定页面读取

Autoloom 将“发现信息”和“读取已知页面”作为两项独立操作。执行 `web_search` 时，会先请求当前步骤实际选中的模型路由完成一次隔离的托管搜索；这次辅助请求只包含固定搜索指令和查询内容，并且只有供应商明确返回服务端搜索工具已经执行的证据时才会采用结果。

只有模型路由明确不支持托管搜索或没有实际执行搜索时，Autoloom 才会使用你在**设置 → 插件 → 网页搜索**中选择的独立搜索服务。认证、额度、超时、传输和供应商服务器故障会保留为明确错误，不会悄悄把查询转给另一家服务。托管搜索与兜底服务都不可用时，界面会提示具体配置位置。

读取指定 HTTP(S) 地址时会直接使用 `web_fetch`，不依赖搜索能力，并且只允许访问公网目标。搜索结果与网页正文会作为不可信参考数据交给 Agent，页面中夹带的指令不能覆盖你的要求或 Autoloom 规则。

当前 Alpha 中，`web_search` 适用于本地项目；SSH 项目会明确报告搜索不可用，不会把搜索凭据复制到远端主机。

## 常见错误

- **缺少凭据**：保存所需密钥或登录对应账户后重试。
- **未知模型**：选择目录中已有的模型，或把准确的模型 ID 添加到自定义供应商。
- **401 或 403**：检查凭据、账户权限、接口地址，以及供应商要求的区域或项目配置。
- **429 或额度错误**：检查供应商的限流、余额和计费状态。
- **连接或超时错误**：确认 Windows 电脑能够访问接口；SSH 项目的模型请求仍从本机派发。
- **自定义网关拒绝所有请求**：重新核对协议，以及网关对 system/developer 角色、推理字段和 token 上限字段的兼容性。
- **图片在发送前被拒绝**：选择目录中明确支持图片的模型，或配置自定义模型的输入能力。

请勿在公开 Issue 中提交仍然有效的密钥或未经脱敏的供应商错误内容。
