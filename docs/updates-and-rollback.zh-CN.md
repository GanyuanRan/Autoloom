# 更新与回退

[English](updates-and-rollback.md) | 中文

Windows 安装版会检查本仓库公开的 Beta 发布源。自动检查和下载默认开启，可在**设置 → 通用**中修改。

Alpha 13 可以直接发现 Beta 1，并通过一次明确的重启安装。更早的 Alpha 客户端须先安装 Alpha 13，或手动安装 Beta；Beta 客户端接收更高的 Beta 或正式版，排除 Alpha。

## 安装更新

发现新版本后，Autoloom 会在后台下载完整安装包，并在校验通过后显示**重启更新**。只有点击该操作才会开始安装；普通关闭应用不会安装已经下载的更新。

更新前请完成或停止活动中的模型、工具、项目及后台任务。准备更新时，Autoloom 会暂停接收新任务、刷写 Session、关闭本地与 SSH Host，然后安装已经验证的包并重新打开应用。设置、Session 和项目都位于应用安装目录之外，安装器会保留它们。

仍在使用早期 ZIP 解压版的用户，需要手动安装第一个安装器版本。

## 手动更新或修复安装

自动下载失败时：

1. 备份重要项目和任务记录。
2. 从 [GitHub Releases](https://github.com/GanyuanRan/Autoloom/releases) 下载目标安装包与 `SHA256SUMS`。
3. 核对 SHA-256。
4. 关闭 Autoloom 并运行安装包。

修复损坏的安装也可采用相同步骤。重新安装应用时，不要删除 `%USERPROFILE%\.autoloom` 或项目中的 `.autoloom` 目录。

## 回退版本

Autoloom 目前没有应用内回退按钮。Beta 阶段的数据格式可能变化，旧客户端可能拒绝新客户端写入的设置或 Session 数据。

更新前请为当前版本保留对应备份。需要尝试回退时，先关闭 Autoloom，从旧版本的 Release 下载并校验安装包，同时阅读该版本的兼容性说明。如果旧客户端拒绝当前数据，请恢复与旧版本匹配的更新前项目和 Autoloom 数据备份。没有匹配备份时，应重新安装最新版，不要手工修改存储记录。

安装旧版本不会撤销 Agent 已经对项目文件或外部系统做出的更改；这些内容应通过项目版本控制或对应外部服务的恢复机制处理。

## 来源验证与 Beta 限制

当前 Beta 安装包没有 Windows 代码签名，因此可能出现未知发布者或 SmartScreen 提示。请只使用本仓库提供的安装包并核对 `SHA256SUMS`。每个 Release 会说明变更与验证范围；安装或界面检查通过，并不代表所有真实供应商流程都已完成端到端验证。
